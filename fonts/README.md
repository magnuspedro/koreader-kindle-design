# Fontes

Uso as fontes "NV" do projeto [ebook-fonts](https://github.com/nicoverbruggen/ebook-fonts)
de Nico Verbruggen (versões ajustadas para e-readers):

- NV Bitter · NV Charis · NV Legible Next · NV Libertinus · NV Literata

Os arquivos `.ttf` não ficam neste repositório. Uma das fontes (Legible Next, baseada na Atkinson Hyperlegible)
não permite redistribuir versões modificadas. Baixe no projeto original e copie para `koreader/fonts/` no Kindle.
